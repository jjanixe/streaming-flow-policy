# Publication and public-source audit

Checked 2026-09-11. Venue status and code status are separate. “Unverified” means this audit did not locate a matching official acceptance/proceedings record; it does not prove rejection or nonpublication. Code verification means source files were read, not that the experiments were reproduced.

공식 게재와 공개 구현이 함께 확인된 주요 근거는 **DynaGuide (NeurIPS 2025), Guided SSIP (RSS 2026), Batch Active (CoRL 2018), PFM (NeurIPS 2024), SFP (CoRL 2025)**이다. **FPL의 CoRL 2026 표기는 근거가 확인되지 않아 수정했다.** UF-OPS/FPL의 공개 구현은 확인했지만 게재 기록은 미확인이고, FlowPRO는 저자 페이지 기준 심사 중·코드 공개 예정이다. 동료심사 게재는 현재 제안한 few-shot 조합의 성능을 보장하거나 그 조합 자체를 검증했다는 뜻은 아니다.

## Strongest usable intersections

- Peer-reviewed + relevant frozen robot-policy guidance + source: DynaGuide (NeurIPS 2025) and Guided SSIP (RSS 2026).
- Peer-reviewed + trajectory preference acquisition/active query algorithm + source: Batch Active (CoRL 2018).
- Peer-reviewed + flow preference theory + source: PFM (NeurIPS 2024), with task/domain differences.
- Peer-reviewed + base streaming robot flow policy + source: SFP (CoRL 2025).
- PC-Flow, RKO, FDPP have publication evidence, but public official code remains unverified.
- FPL and UF-OPS have substantial source, but verified peer-reviewed publication evidence remains absent in this audit. FlowPRO remains under review / code coming soon.
