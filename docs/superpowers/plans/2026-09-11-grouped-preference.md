### Task 1: Bounded two-group features and fitting

Own only `env/grouped_preference.py`, `env/tests/test_grouped_preference.py`.

Implement dataclasses `GroupedPreference(weights, alpha)` with validated float64 shapes (2,2) and (2,), finite nonnegative simplex entries. `GroupedFit` has `preference`, `objective`, `converged`, `iterations`, `projected_gradient_norm`, `jacobian_rank`, `scope_counts`, and preferably staged initialization diagnostics. Provide:

- `grouped_features(positions, *, y_scale=.35)`: finite full paths ending [65,2] -> [...,2,2], using float64 mean of the 64 post-initial rho values. d=mean(rho), e=mean(rho^2); D=((1+d)/2,(1-d)/2), W=(e,1-e).
- `grouped_utility(features, preference)` -> leading-shape values, permits all-zero failure features.
- `grouped_probabilities(delta_features, scopes, preference, *, rho=16.)`, delta shape [N,2,2], scopes strings direction/width/overall. Logit is rho*dot(w_r,delta_f_r) scoped, rho*sum(alpha_r*dot(w_r,delta_f_r)) overall.
- `fit_grouped_preference(delta_features, labels, scopes, *, rho=16., l2=.1, max_steps=300)` labels +/-1. Optimize average logistic loss separately per nonempty scope, summing the scope means, plus l2 times squared distance of all three free coordinates (w_D[0],w_W[0],alpha[0]) from .5. Empty scopes contribute zero. First fit each w from its scoped labels and alpha from overall given w. Then deterministic bounded joint L-BFGS-B multi-start including staged and uniform initializations, choosing the lowest objective; analytic gradient. Return projected-gradient and rank of the unregularized logit Jacobian, not an unsupported global-optimum claim. Validate shapes, finite values, rho>0, l2>=0, nonempty data and integer limits.
- `grouped_metrics(delta_features, labels, scopes, preference, *, rho=16.)`: overall aggregate and scope-specific count, cross entropy, accuracy (zero logit prediction +1). No truth-based fitting.
- `build_grouped_queries(seed, count=40)` returns trajectories [N,2,65,2], ids [N,2], scopes [N]. Reuse analytic generator geometry from run_preference without modifying it; select direction geometry for D, width for W, tradeoff for overall, with per-ten scope pattern D,W,O,D,W,O,D,W,O,O. Independent query selection from user, nested deterministic prefix even for different requested counts.
- `synthetic_grouped_users()` returns eight named GroupedPreference values: names `upper_narrow_direction`, `upper_narrow_width`, etc. Within desired feature .9, other .1; alpha direction-priority (.8,.2), width-priority (.2,.8).

Test formula values/bounds/complementarity, swapping upper/lower symmetry, simplex rejection, scoped probabilities independent of alpha, beta/gibbs logit parity, seeded query scope counts/prefix independence, synthetic deterministic population recovery (soft expected labels may be replicated to yield stable finite-sample counts), overall-only rank <=2 versus scoped rank3, positive regularization no-data-scope handling, large logits/stability and convergence honesty. Avoid tests merely mirroring internals. Read `env/preference.py`, `env/features.py`, query geometry in `env/run_preference.py` for context. Report exact tests and outcomes, no commit.
